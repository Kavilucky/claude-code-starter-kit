# Правила запуска тестов
Это правило подгружается только при работе с файлами тестов (маска `paths` выше).

- Запускай тесты командой из раздела «Команды» корневого CLAUDE.md. Если её там нет, остановись и сообщи об этом, не угадывай.
- Сначала запускай тесты изменённого модуля, потом весь набор.
- Новый тест сначала должен падать без исправления, потом проходить с ним.
- Не удаляй и не ослабляй существующие проверки, чтобы тест прошёл. Если проверка устарела, объясни почему.
- Не обращайся в тестах к сети и к реальным ключам: данные и ответы подменяй.
- В отчёте показывай фактический вывод команды: кто проверяет цель `/goal`, судит только по тому, что показано в разговоре.
