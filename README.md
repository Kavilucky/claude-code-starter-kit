# Claude Code Starter Kit — архитектура памяти, субагенты и безопасный автономный контур

Готовые шаблоны к видео «Claude Code от А до Я: как заставить агента работать часами и не тупеть». Всё можно открыть и прочитать до запуска: секретов и скрытых действий в репозитории нет.

## Быстрый старт

```bash
git clone https://github.com/Kavilucky/claude-code-starter-kit.git .
```

Команда клонирует шаблон в текущую папку, поэтому она должна быть пустой. Чтобы добавить комплект в существующий проект, клонируйте в отдельную папку и перенесите нужные файлы вручную: уже имеющиеся `CLAUDE.md` и `.claude/settings.json` не затирайте, а объедините.

Дальше:
1. Замените текст в угловых скобках и команды в `CLAUDE.md`, проверьте командой `/context`, что файл виден в разделе Memory files.
2. В `.claude/settings.json` замените `C:/путь/к/проекту` на абсолютный путь к проекту (если нужен звуковой хук).
3. Перед автономной работой сделайте копию: `backup_project.bat E:\backup` (Windows) или `./backup_project.sh /mnt/backup` (Linux, macOS).
4. Запустите первый контур на маленькой задаче: `/goal все тесты проходят и линтер чистый, покажи вывод команд, или остановись после 20 ходов`.

## Пять модулей

| Модуль | Файлы | Что делает |
|---|---|---|
| Компактный CLAUDE.md | `CLAUDE.md` | Карта проекта короче 200 строк: команды, правила, правила автономной работы, Compact instructions. Подробности вынесены в другие файлы |
| Изолированные правила | `.claude/rules/tests.md` | Правила, которые подгружаются только для файлов, подходящих под маску `paths` (здесь тесты) |
| Скиллы субагентов | `.claude/skills/*/SKILL.md` | `codebase-audit` (агент Explore, только чтение), `test-generator`, `auto-docs`: `context: fork`, запуск только вручную |
| Хуки | `.claude/settings.json`, `scripts/hook_sound.py` | Звуковой сигнал, когда работа действительно закончилась: хук Stop ждёт паузу и играет сигнал, если новых ходов нет |
| Резервная копия 3-2-1 | `backup_project.bat`, `backup_project.sh`, `BACKUP-3-2-1.md` | `git bundle` со всей историей и проверка; памятка по правилу 3 копии, 2 носителя, 1 вне места работы |

Лимит ходов у `/goal` задаётся текстом условия; отдельной настройки в `settings.json` для него нет.

## Ограничения

- Комплект написан по документации Claude Code. Режимы разрешений, доступность auto и поведение `/goal` зависят от версии и аккаунта: проверяйте на небольшом проекте.
- `git bundle` хранит только закоммиченное. Файлы из `.gitignore` (`.env`, базы, артефакты сборки) копируйте отдельно и храните зашифрованными.
- Скилл `test-generator` не знает вашу команду тестов: она должна стоять в `CLAUDE.md`.
- Звук хука на macOS и Linux зависит от системных проигрывателей (`afplay`, `paplay`) и может отсутствовать.
- Если третью копию вы держите на своём сервере за Cloudflare Tunnel: по документации Cloudflare на бесплатном тарифе зоны максимальный размер загрузки через прокси 100 МБ, ожидание ответа origin 125 секунд, простой соединения 900 секунд ([cache](https://developers.cloudflare.com/cache/concepts/default-cache-behavior/), [connection limits](https://developers.cloudflare.com/fundamentals/reference/connection-limits/), проверено 2026-10-21). Тяжёлые данные копируйте по локальной сети или на внешний диск. Условия использования и актуальные лимиты проверяйте сами.
- Это не замена ревью: автономный результат читайте так же внимательно, как работу коллеги.
