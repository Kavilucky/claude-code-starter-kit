# Памятка: резервная копия по правилу 3-2-1

Перед запуском автономной работы агента (`/goal`, режим auto, длинная сессия) сделайте копию. Агент правит файлы без вас, и откат только через Git возможен не всегда.

## Правило
- **3** копии данных: рабочая и ещё две.
- **2** разных типа носителей: например, внутренний диск и внешний диск либо облако.
- **1** копия вне вашего места работы: удалённый репозиторий, облачное хранилище, диск в другом помещении.

## Почему одного Git мало
Git не хранит: незакоммиченные изменения, файлы из `.gitignore` (часто `.env`, локальные базы, `node_modules`, артефакты сборки). Если репозиторий лежит на одном диске, копия по-прежнему одна. Удалённый репозиторий закрывает пункт «вне места работы» только для закоммиченного.

## Минимальный порядок перед автономным запуском
1. Посмотрите состояние: `git status`
2. Закоммитьте всё нужное: `git add -A` и `git commit -m "checkpoint before agent run"`
3. Создайте отдельную ветку для агента: `git switch -c agent/run-01`
4. Отправьте её в удалённый репозиторий: `git push -u origin agent/run-01`
5. Скопируйте папку проекта на внешний носитель
   - Windows: `robocopy "C:\path\project" "E:\backup\project" /E /XD node_modules .git`
   - macOS и Linux: `rsync -a --exclude node_modules --exclude .git /path/project/ /mnt/backup/project/`
6. Для файлов вне Git (например, `.env`) сделайте отдельную копию в зашифрованном виде. Секреты в облако в открытом виде не кладите.
7. Только после этого запускайте автономную работу и задайте лимит ходов в условии цели.

## Копия одним файлом
`git bundle create ../project-YYYYMMDD.bundle --all` создаёт один файл со всей историей. Проверка: `git bundle verify ../project-YYYYMMDD.bundle`. Файл удобно положить на внешний носитель и в облако.

## Проверка восстановления (раз в квартал и после смены схемы)
Копия, которую не пробовали восстановить, не копия. Склонируйте из bundle или удалённого репозитория в чистую папку и запустите тесты проекта.

## Чек-лист перед запуском
- [ ] Всё нужное закоммичено, ветка для агента создана и отправлена
- [ ] Есть копия на втором носителе
- [ ] Есть копия вне места работы
- [ ] Файлы вне Git (`.env`, базы) скопированы отдельно, секреты зашифрованы
- [ ] В условии `/goal` указан лимит ходов
- [ ] Я знаю, как откатиться: ветка агента удаляется, рабочая ветка не тронута
